# 公开发布材料

本目录整理当前原型的公开说明，按 2026-10-10、ABI 0.88 的实际实现和验证证据编写。

| 材料 | 内容 |
| --- | --- |
| [项目摘要](PROJECT-OVERVIEW.MD) | 仓库简介、设计选择、已完成能力与后续方向 |
| [验证记录](VALIDATION.MD) | 平台矩阵、回归证据与验证限制 |
| [首次发布说明](RELEASE-NOTES.MD) | 可作为远程仓库首版发布介绍 |
| [匿名发布指南](PUBLICATION.MD) | 文件范围、匿名历史、许可证和发布命令 |
| [隐私检查工具](tools/check_publication.py) | 扫描候选文件、提交身份及常见敏感内容 |
| [发布快照工具](tools/prepare_publication.py) | 创建独立匿名仓库、源码压缩包与哈希清单 |

根 [README](../README.MD) 是远程仓库的入口。长期架构、工程计划和 TODO 仍保留在根目录，避免在摘要中重复整个演进记录。

匿名发布采用独立初始提交，不带入开发仓库的旧 Git 历史、reflog、本地配置或构建产物。工具输出位于已忽略的 `out/publication/`；此目录是本地发布候选，远程只推送其中独立仓库的 `main` 分支。
